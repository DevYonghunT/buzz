# 서식(템플릿) 폴더

학교에서 실제로 쓰는 양식 파일을 여기에 넣어 두면, 에이전트가 문서를 만들 때
**그 서식 그대로** 만들어 줍니다. 비어 있으면 기본 서식으로 만듭니다.

## 넣는 방법

한글·워드·파워포인트에서 평소 쓰시는 양식을 열어, **내용은 비우고 서식만 남긴
채** 저장해서 이 폴더에 넣으시면 됩니다. 머리글, 학교 로고, 글꼴, 표 틀이
들어 있으면 그대로 쓰입니다.

파일 이름이 곧 용도입니다. 문서 종류를 알아볼 수 있게 지어 주세요.

```
~/.schoolx/TEMPLATES/
├── 가정통신문.hwpx
├── 공문.docx
├── 발표자료.pptx
└── 성적표.xlsx
```

## 표가 있는 서식이 가장 잘 맞습니다

에이전트는 표에서 **라벨 칸을 찾아 그 옆 칸에 값을 채우는** 방식으로
동작합니다. 그래서 이런 모양이 가장 정확합니다.

| 항목 | 내용 |
|---|---|
| 방학 기간 | *(비워 둠)* |
| 개학일 | *(비워 둠)* |

왼쪽 라벨(`방학 기간`, `개학일`)은 그대로 두고 오른쪽 칸을 비워 두시면,
에이전트가 그 자리를 채웁니다. 라벨 문구는 **문서마다 일관되게** 쓰시는 편이
좋습니다.

## 알아두실 점

- **HWPX**: 표와 글은 잘 처리되지만 도형·이미지는 제한적입니다. 로고나 복잡한
  머리글이 필요하면 반드시 서식 파일로 주세요 — 처음부터 만들게 하는 것보다
  결과가 훨씬 안정적입니다.
- **PPTX**: 서식이 없으면 색과 글꼴을 에이전트가 임의로 정합니다. 학교 테마가
  든 파일을 하나 넣어 두시는 것을 권합니다.
- **DOCX**: 제목·본문 스타일이 정의된 문서를 주시면 그 스타일을 씁니다.

## 잘 안 될 때

서식을 넣었는데 반영되지 않으면, 에이전트에게 **어떤 파일을 썼는지** 물어보세요.
파일 이름이 문서 종류와 맞지 않으면 못 찾을 수 있습니다.
